# Raman Noise Characterization in Classical-Quantum Optical Fiber Links

This repository contains the MATLAB code developed for the Master's Thesis focused on the experimental characterization and theoretical analysis of Raman noise in optical fiber communication systems.

## Contents

- Spectral characterization of MUX and DEMUX devices
- Raman noise analysis
- Estimation of the Raman coefficient β
- Power budget calculations
- Bootstrap statistical analysis of the 0 km critical point
- Generation of complementary statistical plots

## Requirements

- MATLAB
